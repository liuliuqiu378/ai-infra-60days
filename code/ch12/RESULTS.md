## 1. offload 悬崖数据（图2 全部数据）

## 2. 并发样例表（4.2 节，官方 README 样例非本机）

- PP=128/TG=128：B=1/2/4/8/16/32 → S_TG = 41.57/50.90/74.44/139.43/242.23/465.40；
  T_PP = 0.108/0.198/0.373/0.751/1.570/3.408 s；聚合 S_PP ≈ 1187–1374 近常数。
- 本章推导列"每路 = S_TG÷B"：41.57→14.54（剩 35%）。

## 3. 三时延算账（3.2 节，算账非实测）

- 输入：权重 8.99 GB（ch10 HF 实测）；GDDR7 标称 448 GB/s；DDR4 有效 25 GB/s（标称/典型值）；
  跨界激活 ~10 KB/边界/量级；PCIe 参照 ch07 实测 18.6 GB/s（4.0 x16）。
- ngl40：显存段 7.49/448 ≈ 16.7ms + 内存段 1.50/25 ≈ 60ms + 跨界 <1ms → ~77ms ≈ 13 tok/s
  （实测 12.5，吻合）；ngl0 → 2.8（实测 2.89）；ngl99 → 48.8（实测 43.18，达 88%）。
- 方案 B 算账：Q2_K 5.77/448 ≈ 13ms → 理论 ~77 tok/s（16G 卡参照系）。
