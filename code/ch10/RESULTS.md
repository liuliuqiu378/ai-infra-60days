## 3. 速度账

- **理论**：decode≈权重字节/带宽（第 3 章 Roofline）。7B Q4 vs f16 =
  15.24/4.68 = **3.26×**。
- **文献**：AWQ TinyChat 边缘端 4-bit vs FP16 **3–4×**（arXiv:2306.00978）。
- **实测（arXiv:2601.14277，Xeon 8488C，llama-bench，llama.cpp b7600）**：

| 档位 | pp512 (tok/s) | tg128 (tok/s) | 量化耗时(s) | 体积(MiB) |
|---|---:|---:|---:|---:|
| F16 | 79.57±1.00 | 2.83±0.01 | – | 15,317 |
| Q8_0 | 71.42±3.15 | 5.03±0.16 | 29.3 | 8,138 |
| Q6_K | 59.81±1.07 | 6.33±0.13 | 31.2 | 6,283 |
| Q5_K_M | 58.24±2.05 | 6.85±0.13 | 36.5 | 5,460 |
| Q4_0 | 97.35±0.68 | 4.36±0.20 | 27.4 | 4,438 |
| Q4_K_M | 87.70±0.70 | 5.12±0.37 | 42.2 | 4,685 |
| Q3_K_M | 68.86±1.36 | 6.52±0.23 | 31.8 | 3,825 |
| Q3_K_S | 57.39±3.01 | **9.91±0.03** | 27.0 | 3,487 |

（decode 3.5×（Q3_K_S vs F16）；prefill **非单调**：Q4_0 最快 97.35，
低 bit 解包开销使 Q3_K_S 回落 57.39。）

## 4. 理论口径与外部引用

- **Q4_K_M bpw**：官方文档 "≈4.89 bits/weight"；本文 7B 实测有效 bpw
  4.92，一致。
- **GQA 卡片（ch04 补充）**：Llama-2 arXiv:2307.09288（34B/70B 用 GQA；
  多数任务≈MQA 更优/接近 MHA）；Mistral 7B arXiv:2310.06825（摘要
  GQA "faster inference"+SWA；32 Q 头/8 KV 头/head_dim128 → KV=MHA 的 1/4）。
- **vLLM 卡片（ch03 补充）**：官方基准 ShareGPT 上比 HF Transformers
  14–24×、比 TGI 2.2–3.5×；SOSP'23 论文同延迟比 FasterTransformer/Orca
  2–4×、KV 浪费 60–80%→<4%（arXiv:2309.06180）。
- **KLD 指标依据**：Unsloth 引 *Accuracy is Not All You Need*，KLD 与
  flips 强相关，PPL 会因误差抵消而"骗人"。
