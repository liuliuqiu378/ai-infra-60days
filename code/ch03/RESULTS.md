# 第 3 章 实测原始记录（数字溯源）

- **日期**：2026-10-15
- **硬件**：RTX 4090 D，24 GB GDDR6X，驱动 580；实测显存可用 23.5 GB
- **软件**：torch 2.10.0+cu128，transformers 4.56.2，bf16，CUDA Event 计时（warmup 后多次平均）
- **模型**：Qwen2.5-0.5B（N=0.494B 参数，bf16 权重 0.988 GB；24 层，hidden 894，vocab 151,936）

## 0. 硬件"两堵墙"微基准（02_roofline_microbench.py）

| 测量 | 结果 | 备注 |
|---|---|---|
| bf16 大矩阵乘峰值（12288³） | **146.0 TFLOPS** | 4090 D dense bf16 Tensor Core 标称约 147；**82.6 TFLOPS 是 FP32 指标，勿混用** |
| 大张量 copy 有效带宽（4 GB） | **920 GB/s** | 标称 1008 GB/s 的 91%（读 1 份+写 1 份计 2N 字节） |
| Roofline 拐点 AI* = 算力/带宽 | **158.7 FLOP/byte** | AI 低于此值受带宽限制，高于此值受算力限制 |

## 1. prefill（01 脚本 A 组，FLOPs≈2N·S，忽略 attention O(S²)）

| S（一次喂入 token） | 耗时 | 均摊 ms/token | achieved TFLOPS | 占峰值 |
|---|---|---|---|---|
| 128 | 14.33 ms | 0.112 | 8.8 | 6.0% |
| 512 | 14.31 ms | 0.028 | 35.3 | 24.2% |
| 2048 | 24.63 ms | 0.012 | **82.2** | 56.3% |
| 4096 | 57.27 ms | 0.014 | 70.7 | 48.4% |

S=2048 时均摊 0.012 ms/token ≈ **83,000 tok/s**。短序列利用率低是矩阵形状小 + kernel launch 固定开销所致。
